# Graphie
Graphie is a minimal whiteboard built with React and TypeScript, designed to bring ideas to life on a clean, interactive canvas.

## Tech Stack

- **React** for the UI
- **TypeScript** for type safety
- **Vite** for development and building
- **CSS / HTML** for styling and structure

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/ishan-iso/Graphie.git
cd Graphie
```

Install dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
